# Происхождение основы

В `app/` импортированы отслеживаемые Git исходники [BrainDrive](https://github.com/BrainDriveAI/BrainDrive), commit `6748ca07a74e51e605efdbd5509f999c727a2d8a`, через `git archive`. В коммит включены 449 из 452 upstream файлов: исключены два файла кэша `client/.vite/deps/` и `client/tsconfig.tsbuildinfo`. Исходная история Git и локальные зависимости/секреты/память не импортированы. Вложенного репозитория или submodule нет.

Исходный код импортирован без изменений. Наш первый дополнительный файл внутри основы — `builds/typescript/features/contracts.ts`, контракт планируемых функций хакатона. Последующие доработки отслеживаются отдельными коммитами.

Лицензия: [MIT](app/LICENSE). Сохранены copyright и [политика товарного знака](app/TRADEMARK.md). Собственному продукту требуется своё название; указывать «Built on BrainDrive» допустимо. Исходные CI workflows находятся внутри `app/.github` и не являются workflows корневого репозитория.

До импорта эта версия прошла локальные сборки backend, MCP и frontend и проверку HTTP старта. Полный сценарий авторизации/LLM не проверялся. Локальные исследовательские файлы находятся вне публикуемой основы.
