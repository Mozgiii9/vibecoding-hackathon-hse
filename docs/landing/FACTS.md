## Подтверждённые возможности

| Публичная формулировка | Основание и точная граница |
|---|---|
| «Поставьте цель и согласуйте критерии» | [PRODUCT.md](../../PRODUCT.md), [контракт](../contracts/API_V1.md), [приёмка A](../release/ACCEPTANCE.md): ручная форма, три критерия, обычная авторизация. LLM-интервью для постановки цели не входит в этот сценарий. |
| «Добавьте текст, проверьте найденные события по цитате» | [Приёмка A](../release/ACCEPTANCE.md): локальный live Gemini desktop/mobile-проход прошёл; источник и точная цитата проверены. Это реальная модель, отдельный первоначальный `provider_failed` тоже зафиксирован. Не обещать безошибочное понимание любого текста. |
| «Вы решаете, что засчитать в прогресс» | [Расчёт прогресса](../../app/builds/typescript/features/goals/progress.ts), [приёмка A](../release/ACCEPTANCE.md): считаются подтверждённые выполненные действия. Намерения не увеличивают счётчик; повтор того же источника не даёт вторую единицу, отклонение пересчитывает результат. Похожий смысл разных текстов не равен гарантированной дедупликации. |
| «Видно, что уже сделано по каждому критерию» | Серверные числа по критериям, без общего процента жизненного успеха. Следующий шаг в v1 — правило по первому незавершённому критерию, не модельный коучинг: [progress.ts](../../app/builds/typescript/features/goals/progress.ts). |

## Аудио: реализация и приёмка различаются

В этом SHA уже есть настоящий [STT-адаптер](../../app/builds/typescript/features/context/stt.ts) и отдельный [faster-whisper сервис](../../services/stt/README.md). Сохранены [реальная расшифровка синтетического аудио](../demo/sources/demo-audio-transcript.json) и [метрики одного запуска](../demo/sources/audio-metrics.json): запись 50,63 с обработана за 15,64 с. Это единичный замер, не SLA; в расшифровке есть ошибки. Таймкоды допустимы только из фактических segments. MVP показывает расшифровку, аудиоплеер не заявлен.

Полный путь «аудио через UI → STT → модель → цитата → подтверждение → прогресс» в [журнале приёмки](../release/ACCEPTANCE.md) остаётся **NOT_RUN**. Наличие [browser runner](../evaluation/browser-audio-README.md) не означает PASS. Старые README и передачи команды со словами «STT ещё не реализован» отстают от исходников; их нельзя использовать как текущее описание реализации. Безопасная публичная формулировка: **«Короткое аудио — в проверке»**. Не писать «аудио MVP принято» или «полный MVP готов» до приёмки одного общего SHA.

- [Четыре HTML-слайда](../demo/defense/README.md) подготовлены. [Резервное видео и две человеческие репетиции](../demo/REHEARSAL.md) отмечены **NOT_RUN**; файла готового продуктового видео в срезе нет. Не добавлять кнопку воспроизведения без реального файла.
