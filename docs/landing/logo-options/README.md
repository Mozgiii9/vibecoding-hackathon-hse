# Три векторных направления «Рядом»

Концепты для выбора владельцем, 25 октября 2026. Продуктовый сайт и favicon не заменены. Варианты находятся только в `docs/landing/logo-options/`.

## Источник процесса

Сначала применён локальный `find-skills`, затем найден и прочитан публичный [logo-design / SKILL.md](https://github.com/kaankiziltug/logo-design-skill/blob/main/skills/logo-design/SKILL.md) от kaankiziltug. Дополнительно прочитаны [SVG construction](https://github.com/kaankiziltug/logo-design-skill/blob/main/skills/logo-design/references/svg-construction.md) и [testing checklist](https://github.com/kaankiziltug/logo-design-skill/blob/main/skills/logo-design/references/testing-checklist.md). [Карточка skills.sh](https://www.skills.sh/kaankiziltug/logo-design-skill/logo-design) на момент поиска показывала 1K установок и 4.5K GitHub stars. Это независимый автор, не официальный пакет OpenAI.

Skill прочитан без глобальной установки. Его Python-скрипты и сторонний исполняемый код не запускались. Выбран быстрый процесс: готовый контекст → три разных идеи → настоящая SVG-геометрия → просмотр малого размера и монохрома → выбор владельца до полной айдентики. Применены ограничения: один смысл на знак, простые контуры, `viewBox`, отсутствие растра, эффектов и шрифтов в SVG. Проверка написана локально на существующем Playwright.

## Бриф

«Рядом» — тёплый личный помощник, связывающий контекст с подтверждёнными шагами к цели. Характер: внимательный, спокойный, конкретный. Знак должен работать с русским названием, на тёмном сайте и рядом с пиксельным светлячком, не копируя персонажа. Основной носитель — шапка сайта, символ 16/32 px. Базовые цвета: фон `#24211f`, абрикос `#e5b68d`, кремовый `#f4eadf`, шалфей `#b8c5a5`.

В кратком поиске идей рассмотрены: спутник у открытой дуги; непрерывная нить шагов; монограмма Р.; две скобки вокруг общего пространства; парные огни; закладка с вырезом; два следа; луч с точкой. Отобраны первые три за разные силуэты и связь с именем/характером/действием. Буквальный мозг, робот, галочка, мишень и стрелка вверх исключены как слишком прямолинейные для личного помощника.

## Варианты

| Выбор | Файл | Идея | Конструкция | Компромисс |
| --- | --- | --- | --- | --- |
| **A — Спутник** | `01-sputnik.svg` | Мягкое присутствие рядом с точкой света | Круговая дуга толщиной 48 единиц; круг радиуса 28 в открытой четверти | Абстрактный знак потребует знакомства с именем |
| **B — Нить шагов** | `02-nit.svg` | Небольшие шаги соединяются в путь | Заполненная лента шириной 40; внешние закругления радиуса 20; отдельная точка | Может напоминать график роста; менее спокойный характер |
| **C — Р.** | `03-monogram.svg` | Первая буква имени и точка завершённого действия | Геометрическая кириллическая Р с настоящим отверстием, отдельная точка | Самая буквальная идея; буква Р совпадает формой с латинской P |

Рекомендация: **A** — лучше поддерживает тёплый характер и перекликается со светлячком через маленький световой акцент. B подходит, если важнее показать движение. C — если важнее закрепить название.

Каждый SVG: `256 × 256`, прозрачный фон, два заполненных элемента, `currentColor` с тёмным цветом по умолчанию на корневом `svg`, без `text`, `image`, фильтров, масок и внешних ресурсов. Цвет меняется CSS-свойством `color` непосредственно на inline SVG. Файлы с `<img>` используют собственный цвет; перекрасить их стилем родителя нельзя. Текст «Рядом» на HTML-странице — демонстрация сочетания с системным sans, а не финальный шрифтовой мастер.

## Проверка и просмотр

- `index.html` — автономное сравнение: крупный знак, пример с названием, 64/32/16 px, тёмный и светлый монохром.
- `comparison.png` — общий кадр страницы; `concepts-monochrome.png` — нейтральный обзор A/B/C.
- `check-report.json` — результаты headless Chrome: одинаковые контуры в SVG и HTML, отсутствие недопустимых элементов, отсутствие переполнения на 320/390/900/1440 px и ошибок страницы.
- Два визуальных прохода: проверка основных форм/счётчиков/зазоров; затем монохром, реальные малые размеры и подписи A/B/C. Силуэты различимы в 16 px, зазоры сохраняются. Второй проход изменил только обозначения выбора, после чего кадры пересняты.
- Первоначальный рендер ImageMagick не отобразил `currentColor`; пустой результат был отброшен. Итоговые PNG получены Chromium и просмотрены. Первый запуск Chrome внутри sandbox не стартовал; разрешённый headless запуск завершился успешно.

Повторить из корня worktree, указав существующий установленный Playwright:

```sh
# Проверить исходники и страницу, переснять PNG в этой директории.
PLAYWRIGHT_MODULE='/absolute/path/to/playwright/index.mjs' node docs/landing/logo-options/check-preview.mjs
```

Это этап выбора концепции. Финальный шрифтовой логотип, favicon и набор размеров готовятся после выбора. Проверка товарных знаков и расширенный поиск сходства не выполнялись; библиотечные чужие логотипы не копировались.
