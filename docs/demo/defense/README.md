# Локальная защита «Рядом»

[Открыть четыре экрана](index.html). HTML автономен: без CDN, внешних шрифтов, аналитики, запросов к модели и сетевых изображений. Можно открыть файл напрямую в браузере. Внутри презентации нет ключей, пользовательской памяти или приватных записей.

- `index.html` — презентация для показа с клавиатуры и печати браузером.
- [SLIDES.md](SLIDES.md) — редактируемый текст экранов и основания формулировок.
- [DEMO_SCRIPT.md](../DEMO_SCRIPT.md) — речь, живые действия, хронометраж и резервный порядок.
- [REHEARSAL.md](../REHEARSAL.md) — две человеческие репетиции и workflow резервного видео. Репетиции и видео отмечены NOT_RUN до фактического выполнения.

## Управление

| Клавиша | Действие |
|---|---|
| Стрелка вправо/вниз, пробел, Page Down | Следующий экран |
| Стрелка влево/вверх, Page Up | Предыдущий экран |
| `1`–`4`, Home, End | Прямой переход |
| `F` | Полный экран, если браузер разрешает |
| `N` | Заметки в этом же окне |
| Escape | Закрыть заметки, браузер также управляет выходом из полного экрана |
| Tab, Enter | Кнопки и ссылки с видимым фокусом |

Перед проекцией закрыть заметки. Ссылки `#slide-1`…`#slide-4` открывают нужный экран. На телефоне длинный экран можно прокручивать. Печать браузером включает все четыре экрана независимо от выбранного. Экспорт PDF не заменяет проверку печатной версии на целевой машине.

## Границы комплекта

Локальный формат — HTML и Markdown. PPTX и PDF не создавались. Слайды не требуют сервера, сборки или установки пакетов. Добавлены [настоящие резервные записи](recordings/README.md), включая production eba453c. Проверки артефакта не означают репетицию человека или проверку в PowerPoint.

Последний экран обновлён по фактической приёмке C: eba453c прошёл настоящий текст и аудио через UI, confirm/progress/duplicate/reject и backup/restore. A независимо проверил ef360ae с идентичными исходниками runtime; его resume-скрипт C дополнительно выполнил на точном eba453c. [Различия SHA и метод проверки](../evidence/c-production/summary.json) сохранены, выполнение A на точном deployment SHA не выдумывается. Ручная цель и nextStep по правилу остаются видимыми ограничениями.

## Проверка локального артефакта

25 октября 2026, изолированный headless Chrome: четыре экрана при 1280×720 и 1920×1080 помещаются выше панели навигации. На 390×844 нет горизонтального переполнения, длинные экраны прокручиваются. Проверены стрелки, пробел, прямой переход, граница последнего экрана, вход по hash, заметки, Escape и fullscreen. В print media видимы все четыре экрана. Ошибок JavaScript и внешних HTTP-запросов не зафиксировано. Четыре desktop-скриншота просмотрены визуально.

Физический проектор, PDF и обе человеческие репетиции не проверялись. Продуктовая приёмка подтверждается отдельными [production evidence](../evidence/c-production/summary.json), а не наличием этих слайдов.
