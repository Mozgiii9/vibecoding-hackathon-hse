# «Рядом»: текст четырёх экранов

Исходный текст к [index.html](index.html). Рабочий MVP проверен C на production-кандидате eba453c: текст, аудио, review и restore. Доказательства в [summary](../evidence/c-production/summary.json); человеческие репетиции не подменяются технической приёмкой.

## 1. Проблема

Личная учебная или карьерная цель

**Рядом**

Прогресс по цели с понятным основанием

> «Завтра хочу отправить резюме»

Намерение ещё не подтверждает выполненное действие.

## 2. Рабочий сценарий и польза

Демонстрационный сценарий

**Подготовка к ML-собеседованию**

1. Цель с критериями задаёт человек.
2. Новая заметка даёт предложение события.
3. Человек проверяет цитату и подтверждает.
4. Прогресс показывает выполненное по критерию.

Польза: видно, какое действие засчитано и откуда оно взялось. Для показа используем синтетические данные.

## 3. AI pipeline, цитаты и confirm

**Основание каждого изменения**

| Этап | Содержание |
|---|---|
| Источник | Текст и критерии цели |
| Модель | Тип события и точная цитата |
| Проверка | Схема, критерий, совпадение цитаты |
| Confirm | Решение человека. Пересчёт в core |

Намерения не увеличивают счётчик. Человек может пересмотреть подтверждение.

Следующий шаг в v1 выбирает правило по незакрытому критерию.

## 4. Собственный вклад и ограничения

**Наш вклад поверх BrainDrive**

| BrainDrive, MIT | Рядом |
|---|---|
| Авторизация и gateway | A: core целей и приёмка |
| Чат и файловая память | B: импорт, цитаты и аудиопуть |
| | C: интеграция и интерфейс review |

**Рабочий MVP.** Кандидат eba453c проверен: текст, аудио, точные цитаты, пересмотр прогресса и восстановление памяти.

Цель вводится вручную. LLM-интервью не реализовано. Следующий шаг работает по правилу.
