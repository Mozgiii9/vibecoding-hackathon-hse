# Резервная запись настоящего интерфейса

[Текстовый проход ef360ae](text-ef360ae/completed-text/demo.webm), WebM около 1 МиБ, 1440×900, воспроизведённая длительность 15,04 с. [Metadata](text-ef360ae/metadata.json) содержит реальные timestamps, шаги и происхождение SHA. Запись сделана 25 октября 2026, около 14:33 МСК; полный wall-clock запуска с браузером и финализацией указан в metadata и отличается от длительности видеопотока.

Это локальный dev-runtime, синтетический аккаунт и настоящая модель с серверной приватной конфигурацией. Через обычный вход импортирован новый текст про пробное интервью; открыта точная цитата, одно действие подтверждено, серверный счётчик интервью изменился с 0 до 1. Fixture и перехвата ответов нет. Значения паролей в UI маскируются; ключи/headers/cookies/storage state не сохранялись. Финальный кадр видео воспроизведён и осмотрен.

Запись служит коротким текстовым резервом и не доказывает аудио, server release/restart, полный MVP или человеческую репетицию. Runtime SHA при записи — ef360ae; metadata явно отмечает SHA как сообщённый оператором, а не независимо прочитанный с сервера. Актуальные результаты общего кандидата читать в handoff C и release acceptance A.
