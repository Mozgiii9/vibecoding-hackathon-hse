## Показать жюри

1. Открыть события источников с префиксом «Демо · 25 октября». Сравнить утреннее намерение с завершённым действием и переносом второго интервью. Импорт не подтверждает выполнение автоматически.
2. Открыть источник и сверить выделенную дословную цитату. Все новые события остаются на проверке пользователя.
3. Перейти в «Чат с агентом» и задать один из вопросов ниже. Чат должен опираться на сохранённые источники; формулировка и количество выбранных цитат зависят от модели.
4. В чате раскрыть источник ответа. Заметка с личными предпочтениями полезна и без события, привязанного к критерию цели.

## Импорт и проверка

Проверить файлы без сети:

```sh
# Проверяет структуру и уникальность 12 заметок.
node scripts/demo/import-day-context.mjs --check
```

Загрузить в существующий демонстрационный аккаунт:

```sh
# Обычный вход и последовательный импорт через headless Chrome.
# Файл приватный, исключён из Git; содержит RYADOM_DEMO_USERNAME/PASSWORD.
node --env-file=.runtime/record-c.env scripts/demo/import-day-context.mjs --apply
```

Скрипт использует установленный в проекте Playwright и Chrome. Не создаёт цель, не сбрасывает состояние, не подтверждает и не отклоняет события. При повторном запуске использует квитанции ранее сохранённых источников из локальных отчётов и затем проверяет их чтением с сервера. Без квитанции повторный импорт тех же байтов должен вернуть существующий источник. Проверяет дословность цитат, сохранение всех источников после повторного открытия панели, прежние review-решения и подтверждённые счётчики. В конце отправляет один вопрос через интерфейс чата и проверяет время 11:30, ID источника и границы цитат. Отчёт каждого запуска сохраняется отдельно в исключённом из Git `output/test-data/day-context-*/report.json`; ошибка сохраняет частичный результат, поэтому не означает откат уже загруженных заметок.

В первых проходах возникали browser TLS/network ошибки; импорт возобновлён по квитанциям без изменения сервера и без отключения проверки сертификата. Ошибки предыдущих попыток сохранены в `live-result.json`; итоговый проход завершился успешно.
