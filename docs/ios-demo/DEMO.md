# «Рядом»: минутный показ и приёмка iPhone

Цель показа — живой HTTPS web UI в SwiftUI + `WKWebView` оболочке. Оболочка установлена и запущена на физическом iPhone Air / iOS 27.0.1 через Personal Team. Пользователь подтвердил открытие с иконки, но видит «Не удалось загрузить»: кандидат `https://77.239.111.64/` пока недоступен. Пункт 1 PASS, пункты 2–8 NOT_RUN. Вход, обработка моделью и полный MVP не приняты.

## Перед показом

1. Установить приложение по [README.md](README.md), проверить сертификат и доступность web UI с iPhone. Использовать синтетическую тестовую учётную запись и живой сервер без fixture/preview-режима.
2. Проверить общий сервер: вход, модель и STT. Не показывать ключи, URL с токенами или реальные личные данные. Выбрать одну установленную сборку и один web-кандидат для всего прогона.
3. Пройти восемь пунктов ниже заранее. Подготовить цель с тремя критериями, но не зачислять демонстрируемое действие заранее. Пример: «Подготовиться к ML-собеседованию»; критерии: «Отправить резюме» — 1, «Провести пробные интервью» — 2, «Внести правки по обратной связи» — 1.
4. Скопировать текст для импорта: **«Сегодня я отправил резюме на вакансию ML-инженера.»** Это синтетическое выполненное действие. Для отдельной проверки намерения: **«Завтра хочу отправить резюме.»** Намерение не должно увеличивать прогресс.
5. Для аудиопроверки положить в «Файлы» синтетическую запись 20–60 секунд: M4A/WAV/MP3, не более 10 MiB. Например: «Сегодня я провёл первое пробное интервью. Получил обратную связь и записал, что нужно повторить метрики классификации». Использовать другие события для текста и аудио, чтобы дубль не мешал проверке. Не использовать частные разговоры.
6. Потренироваться с реальной задержкой сервиса. При долгой обработке проговорить, что ожидается реальная модель; не подменять результат fixture. Заранее подготовленная запись реального прогона может быть резервом, но должна быть названа записью.

## Минутный показ

| Время | Действие и реплика |
|---|---|
| 0–10 с | Открыть **«Рядом» с иконки iPhone**. «Это iOS-оболочка нашего живого сервиса. Он связывает прогресс с подтверждёнными событиями и источниками». Для минуты сессия уже открыта; отдельная проверка обычного входа выполняется до показа. |
| 10–20 с | Показать цель и три критерия. «Здесь понятные критерии результата; неподтверждённые события прогресс не меняют». |
| 20–35 с | Внести подготовленный текст и нажать **«Найти события»**. Дождаться настоящего результата. «Модель выделяет событие из нового контекста». |
| 35–50 с | У выполненного действия выбрать **«Посмотреть источник»**, показать выделенную исходную цитату. «Решение можно проверить по оригиналу». |
| 50–60 с | Нажать **«Подтвердить»**, дождаться серверного обновления счётчика. «В прогресс попадает проверенное действие». |

Минутный хронометраж — сценарий репетиции, а не гарантия времени ответа модели. Если обработка дольше, дождаться ответа или явно перейти к названной резервной записи; не объявлять ещё не полученный результат успешным. Аудио и повторное открытие приложения входят в отдельную приёмку, их не нужно втискивать в эту минуту. При дополнительном времени показать готовый аудиофайл и реальную расшифровку, только если пункт 8 уже прошёл проверку.

## Физическая приёмка: восемь пунктов

Статусы: **PASS** — воспроизведено на указанном физическом iPhone; **FAIL** — выполнено с неверным результатом; **NOT_RUN** — не выполнялось или зависимость не готова. Сборка для симулятора не меняет эти статусы.

| № | Проверка | Условие PASS | Статус |
|---|---|---|---|
| 1 | Запуск с иконки | После установки из Xcode открыть «Рядом» с домашнего экрана iPhone. Оболочка открылась без падения. Пользователь подтвердил экран сетевой ошибки; загрузка настоящего UI остаётся отдельным blocker для пунктов 2–8. | PASS |
| 2 | Обычный вход | Пройти форму входа в оболочке действующей тестовой учётной записью, получить свой рабочий экран. Предыдущий вход в Safari не засчитывается. | NOT_RUN |
| 3 | Цель и три критерия | Через UI создать/подтвердить цель с тремя критериями; после обновления экрана сохранены те же значения. | NOT_RUN |
| 4 | Текстовый импорт реальной моделью | Импортировать новый синтетический текст через «Найти события»; дождаться настоящего результата общего сервера/модели. Fixture и preview не используются. Событие до подтверждения не зачислено. | NOT_RUN |
| 5 | Исходная цитата | Нажать «Посмотреть источник» у полученного события; показанный оригинал и выделенная точная цитата соответствуют введённому тексту. | NOT_RUN |
| 6 | Подтверждение и прогресс | Подтвердить выполненное действие; после ответа сервера нужный критерий увеличился, повторный просмотр показывает то же сохранённое значение. | NOT_RUN |
| 7 | Сессия после закрытия/открытия | Убрать приложение из переключателя приложений, открыть с иконки без переустановки и выхода из аккаунта. Сессия сохранилась, видны та же цель и серверный прогресс. Зафиксировать интервал между закрытием и открытием. | NOT_RUN |
| 8 | Аудиофайл после готовности общего STT | В «Аудио» выбрать M4A/WAV/MP3 до 10 MiB через «Аудиофайл», запустить обработку. Получены реальная расшифровка и evidence, доступен источник; подтверждение подходящего действия обновляет прогресс. При отсутствии STT оставить NOT_RUN с блокером; если попытка дала ошибку — FAIL. | NOT_RUN |

Микрофонная запись в общем web UI не реализована; пункт 8 принимается по **готовому аудиофайлу**. Не запрашивать разрешение микрофона ради этой проверки и не заявлять, что запись с телефона работает. `stt_unconfigured`, фиктивная расшифровка и придуманные таймкоды не закрывают пункт 8.

## Резерв на защите

Если личная установка через Xcode не готова, вручную открыть настоящий HTTPS UI в Safari. При необходимости добавить его через **Поделиться → На экран «Домой»**. Реплика: **«Сейчас показываю веб-версию в Safari / с веб-ярлыка; установка iOS-оболочки ещё не прошла приёмку»**. Этот резерв не переводит пункты оболочки в PASS.

Если серверное аудио недоступно, показать рабочий текстовый путь и назвать незакрытый аудиопункт. Это сокращённый показ; согласно общей приёмке текстовый путь не подтверждает готовность полного MVP с аудио.
