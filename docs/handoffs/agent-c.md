## Реализовано в нашей части

`gateway/hackathon.ts` создаёт один store и подключает оба модуля под существующими gateway auth hooks. Provider settings читаются только на backend через `hackathon-config.ts`. Полная/частичная конфигурация без значений по умолчанию; неправильные значения диагностируются по имени поля, без секрета.

Frontend: API adapter с runtime-проверками ответов и существующим authenticatedFetch; hook с отменой устаревших запросов, сериализацией mutations и повторной загрузкой серверного прогресса; формы цели/контекста, события и review, точная цитата, фильтры, обработка ошибок/повторов/конфликтов. После входа открывается цель; исходный BrainDrive assistant доступен отдельной кнопкой. Его собственный provider onboarding остаётся отдельной upstream-функцией.

Пользователь утвердил тёплый тёмный стиль и трёхколоночную композицию. Рабочее название — «Рядом». Есть responsive layout, управление клавиатурой, видимый focus, reduced motion, русский lang и разрешённый масштаб страницы. Минимальный текст 12 px. Счётчики берутся из backend, nextStep v1 честно помечен правилом по незакрытому критерию.

`?preview=goals` доступен только в development: синтетические данные, заметная отметка демо, без backend/LLM запросов и сохранения подтверждений. Production build проверен на отсутствие fixture preview.

Сквозной интеграционный тест использует настоящие модули A/B и тестовый extraction provider: create → import → proposed → confirm → progress → source → duplicate → reject → restart. Это проверка соединения модулей и состояния, не живой ответ Gemini. Auth тесты проверяют 401/403 на всех новых endpoints.

Полный backend suite здесь повторно не объявляется зелёным: A отдельно воспроизвёл исходную проблему starter-pack lint на чистой базе. Она описана в его handoff, шаблоны в этом задании не менялись.

## Запуск и оставшееся

1. `npm --prefix app/builds/typescript run dev:hackathon`. Память/секреты по умолчанию в корневом `.runtime/`, первая авторизация через BrainDrive.
2. Рабочий UI: http://localhost:5073. Дизайн без авторизации/личных данных: http://localhost:5073/?preview=goals.
3. Для живого extraction на этой машине нужен локальный `app/builds/typescript/.env.hackathon` по example. B подтвердил протокол OpenAI-compatible chat completions, `gemini-3.8-flash` и три синтетических живых запроса; ключ был только в его environment и на текущую машину не перенесён. Текущий интегрированный запуск без ключа корректно отклоняет импорт.
4. Реальное STT не подключено. B оставил расширяемый transcribe port и честный stt_unconfigured. Наличие faster-whisper на другой машине не означает готовый сервис здесь.
5. Подготовить реальный demo-корпус, выполнить живой проход через авторизацию/UI с настроенной моделью, проверить restart на машине показа и записать резервное видео. Затем принять решение о серверном развёртывании.
