## Цель и очередь

**B1 Проверка STT, до 10 минут.** Проверить реально доступный faster-whisper/endpoint, модель/codecs, обработку записи 20–60 секунд и формат timestamps. Наличие библиотеки на другой машине не равно работающему сервису. Отдельный STT endpoint раньше не подтверждён; `config.stt` пока не реализован. Нет воспроизводимого пути за 10 минут — записать blocker/нужный ресурс и сразу перейти к B3/B4. К 14:30 передать проверенный способ STT или явный риск сроков; аудио входит в целевой полный MVP, text-only остаётся резервным частичным результатом.

**B2 Один transcribe adapter.** Если B1 успешен, подключить один способ через `ContextProviders.transcribe`, сохранив importAudio и атомарную запись в core. Сначала передать C exports/config без ключей и один реальный пример. Проверить на целевой demo-машине, не только в своей среде. Новую зависимость/способ запуска согласовать с C и упаковкой A.

При необходимости отдельный минимальный компонент под `services/stt/**`; Node gateway остаётся основным backend. Python — uv, `.venv`, Pydantic, docstrings, ruff/mypy. Не ставить модели/GPU-драйверы на неизвестный VPS вслепую. Hash от исходных audio bytes с NUL, timestamps только настоящие, отсутствующие времена null, raw audio не сохраняется. Ошибка не оставляет частичного источника. Недоступный сервис даёт stt_unconfigured.

**B3 Качество.** Подготовить 8–10 приёмочных примеров: действие, намерение, отрицание, будущая дата, препятствие, неизвестность, похожий критерий, неоднозначная цитата, инструкции внутри источника. Указать ожидаемые criterion/eventType/цитату. Прогнать доступные реальные запросы Gemini и отдельно parser/unit cases. Это приёмочный набор, не общая оценка качества модели. Исправлять только воспроизведённые prompt/validation/transport дефекты, не ослаблять цитаты или ручное подтверждение.

**B4 Материалы.** Под `docs/demo/sources/` создать 4–6 synthetic источников и ожидаемые события: план, действие, повтор, запись с реальной расшифровкой, если audio принято. Под `docs/evaluation/` — ожидаемое/фактическое и ограничения. Передать C короткое объяснение AI pipeline для защиты.
