# Первый экран личного помощника

**Текущая инструкция владельца: Stitch не использовать, дизайн делать самостоятельно.** История попытки ниже сохранена для контекста и не разрешает новые вызовы Stitch.

Пользователь подтвердил направление и композицию 25 октября 2026. Рабочее название «Рядом»; сценарий — продвижение к ML-собеседованию через подтверждённые события.

## Действие и композиция

Главное действие — проверить извлечённое событие и подтвердить его влияние на заранее согласованный критерий. Слева цель и критерии, в центре события, справа цитата выбранного источника. На телефоне эти блоки идут последовательно, открытый источник доступен с клавиатуры.

Тёмная тема с тёплым, более живым характером личного помощника. Спокойные поверхности, ясные формы, поддерживающий текст, небольшой выразительный знак. Пользователь смотрит личный прогресс на ноутбуке вечером и хочет спокойно разобраться в событиях. Ориентиры взаимодействий — Things, Notion и поддерживающий тон Headspace. Цвет используется для действий и смысловых состояний, не для декоративных метрик.

## Состояния

- Первый запуск: цель и три редактируемых критерия, явное подтверждение.
- Цель с данными: критерии, события, источник, следующий шаг.
- Пустая история: объяснение первого импорта.
- Загрузка: устойчивый layout и текст состояния.
- Ошибка или ненастроенный провайдер: понятное сообщение, повтор, сохранённый черновик.
- Повторный источник: уведомление без роста счётчика.
- Намерение: отдельный смысловой тип, не увеличивающий прогресс.
- Конфликт ревизии: серверные данные перечитаны, действие требует повторной проверки.
- Завершённые критерии: фактические числа без обещания жизненного успеха.

Счётчики и подтверждения принадлежат backend. Фильтры, раскрытие источника и черновик формы принадлежат интерфейсу. Голосование за дизайн не меняет API или правило подтверждения.
