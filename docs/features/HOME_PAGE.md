# Главная страница «Рядом»

Публичный маршрут `/` показывает возможности сервиса до входа. Три основных направления заданы владельцем: проверка пути к целям; развитие навыков по накопленному контексту; помощь в принятии решений с учётом прошлых ошибок.

Главная показывает конкретные примеры для каждого направления, четыре шага работы, интерактивную разницу между намерением и выполненным действием, источники/аудиорасшифровки, чат и FAQ. Визуальная система сохранена: тёплая тёмная палитра, абрикос и шалфей, системный шрифт, Lucide. Новых зависимостей, внешних скриптов и изображений нет.

Текущий чат находит проверенные цитаты из материалов текущей цели. Поэтому навыки и решения объяснены как возвращение к собственной обратной связи и прошлым ситуациям; отдельный профиль навыков или автоматически созданный план не заявляется. Пример на главной явно подписан как синтетический и работает только в состоянии компонента, без API. Нажатия «Подтвердить»/«Отменить» в примере не меняют память и прогресс.

## Переходы

- `/` — публичная главная, не запрашивает config/auth/личный контекст.
- `/app` — защищённое пространство цели; на чистом экземпляре обычное создание владельца, на существующем — вход или восстановление сессии.
- `/login` — обычный вход, затем `/app`.
- `/signup` — штатный signup только на ещё не настроенном экземпляре; существующий владелец переходит на `/login`.
- `/chat` — защищённый чат; адрес сохраняется после входа/перезагрузки. «К моей цели» ведёт на `/app`.

Маршруты восстановления доступа внутри AuthFlow изменены на `/login`, чтобы публичная главная не размонтировала форму восстановления. Logout немедленно скрывает чат и очищает несохранённый черновик. Переход `/app`↔`/chat` сохраняет черновик. Бренд в пространстве ведёт на главную.

Backend API и формат сохранённой памяти не менялись. Существующие release/audio/recording проверки входят в приложение через `/app`; архивные upstream BrainDrive layout tests не относятся к этому MVP.

## Проверка

Полный frontend suite: 252/252 PASS в23файлах. Включены App regression tests: публичная главная без API, переход в пространство, вход с `/login`, сохранение чата/draft, logout, восстановление доступа и redirect настроенного `/signup`. Production frontend build и typecheck PASS.

Локальная браузерная приёмка на изолированной синтетической памяти: 9/9 PASS. Проверены три направления, отсутствие private API до перехода в пространство, локальный пример confirm/undo, клавиатурный FAQ, widths320/375/768/1440 и reduced motion, signup→цель→чат→черновик→logout→recovery→login. Импорта источников и обращений к модели не было.

Первый запуск browser runner остановился до signup из-за второго h1 в ещё исчезающем startup splash. Исправлено ожидание завершения splash в QA, продукт ради этого не менялся; первоначальный FAIL сохранён в `/private/tmp/ryadom-home-local/results.json`.

Визуальное и независимое review проверили copy по трём направлениям, границы контекстных ответов и сохранность auth. Аудиотаймкоды описаны как доступные при наличии результатов распознавания. Физическое мобильное устройство не проверялось; использовался Chrome с эмуляцией размеров.
