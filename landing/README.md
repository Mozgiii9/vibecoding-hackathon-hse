# Лендинг «Рядом»

Самостоятельный статический сайт без сборки, npm-зависимостей, backend и внешних шрифтов. `index.html`, `styles.css`, `app.js`, `config.js` и `assets/` достаточно для размещения. `server.mjs` нужен только при запуске встроенного сервера Node.

## Локальный запуск

Из корня репозитория, Node 22+:

```sh
# Запустить только статический сайт на loopback, без приложения и моделей.
node landing/server.mjs
```

Открыть `http://127.0.0.1:4178`. Порт можно задать через `PORT=4180 node landing/server.mjs`. Остановить Ctrl+C. Для внешнего bind задать `HOST=0.0.0.0`; в обычной разработке это не требуется.

## Ссылка на MVP

Единственный источник ссылки: `landing/config.js`, поле `appUrl`. По умолчанию оно пустое и обе позиции CTA показывают «Ссылка на демо готовится». Ссылка «Посмотреть сценарий» работает независимо. Без JavaScript статический пример и честное состояние остаются доступны.

Интегратор указывает подтверждённый публичный URL обычного входа в приложение. Не указывать preview с fixture, localhost, частную сеть, URL с credentials, токеном/query или hash. Невалидная конфигурация сохраняет состояние ожидания. Проверить вход обычным пользователем вручную: доступный HTML ещё не доказывает готовность MVP.

IP сервера лендинга не является URL MVP. Не направлять CTA в тестовую память A/B и не проксировать их окружение без разрешения. HTTP-лендинг на IP можно просматривать без ввода данных. HTTPS рекомендуется для входа в приложение; HTTP-демо по IP предназначено для синтетических данных.

## Независимая публикация

Скопировать публичные файлы на любой статический HTTP-хостинг. Базовый путь поддерживается: все ресурсы относительные. Для nginx/Caddy не нужны SPA fallback, API proxy или переписывание маршрутов. `server.mjs` обслуживает только явный allowlist публичных файлов, не отдаёт документацию и исходники инструментария.

Лендинг опубликован по подтверждённому адресу `http://77.239.111.64/`. В `index.html` указаны этот canonical, `og:url` и абсолютный адрес `og:image`. При переносе на другой адрес обновить все три значения и повторить проверку. PNG 1200×630 поставляется готовым; `og-source.svg` является редактируемым исходником, его не требуется публиковать.

Шаблон отдельного сервиса и инструкция: `docs/landing/DEPLOYMENT.md`. Не публиковать весь репозиторий, `docs/`, env, recordings, `.git` и приватную память.

## Содержание и проверки

Интерактивный пример детерминирован и работает только в браузере: intention 0 → proposed 0 → confirmed 1 → duplicate 1 → rejected 0. Запросов к AI, аналитики, cookies и форм нет. Он не является проверкой backend.

Фактический статус продукта: `docs/landing/FACTS.md`. Проверки, SHA, адрес публикации и открытые зависимости: `docs/landing/STATUS.md`. При смене релизного кандидата заново сверить аудио и текстовую приёмку. Не менять публичное обещание по одному наличию адаптера.
